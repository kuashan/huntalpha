# V1.1.5 — 后台行情来源选择

## 边界

- 基线为 `V1.1.4`，不改行情解析和交易功能；不变更现有各市场默认来源优先级。
- Django 超级管理员后台新增「行情来源」页面，包含美股、沪深 A 股、港股、加密货币四个独立配置卡片。
- 每个市场默认「自动选择」，**与 V1.1.4 保持一致**，按现有 Router 顺序故障切换。
- 手动选择一个供应商后，报价、历史 K 线、公开轮询实时 K 线、市场指数仅尝试该供应商；供应商不能提供该周期／指数或缺少凭证时显示不可用，**不暗中切换**。
- 证券搜索目录沿用独立的旧目录链，不受报价选择影响；不会改变原有自选和会员资料。
- 加密市场当前仅有 Coinbase；其「自动」与「Coinbase」选项都不会新增其他来源。
- 选择对新的行情请求生效；已打开的浏览器可刷新页面立即使用最新来源。轮询中已有的实时栏位可能在下一次轮询后更新。
- 来源配置持久化到 `core_marketdatasourcesetting`。升级时不预填记录，故没有记录时行为仍是自动模式；回滚旧代码忽略该新表。

## 生产发布安全

- `core.0015_marketdatasourcesetting` 是唯一新增迁移。受控部署工具按 SHA-256 白名单、旧表逐行不变、全新空表、Django 元数据变化等检查，并需先做数据库备份/恢复测试。
- 使用 Codex **本地**测试与 ARM64 构建、推送 GHCR、Digest 受控预检。不要触发 GitHub Actions。
- 完整 Django 测试、真正的 0014→0015 数据库迁移演练、UI 验收未通过前不得合并或部署。生产 V1.1.4 保持冻结。
