截图中高亮的自选行为 **阅文集团 `HK.00772`**，右侧已选择该股票的行情价格 `22.84` 和代码 `HK.00772`，但行情标题仍显示 **焦点科技**；后者真实代码为 `SZ.002315`。

## 已完成的定向调查

- 核对正式 HEAD `1bd064e824161462a5d7b0cc0592a10aeff1cd19`（V1.1.12）；未在生产直接修改代码。
- 生产只读访客 `/api/symbol-search/` 实测：`HK.00772 → 阅文集团 (hk)`、`SZ.002315 → 焦点科技 (cn)`，后端目录及其直接序列化无错，不应重建数据库或修改目录。
- `App.vue` 当前标题从单独的 `selected` 对象取名称/代码，而列表更新维护独立 `symbols` 集合。标题和列表没有“同一代码必须从同一目录行读取显示信息”的统一约束：若之前保留的选中对象的 `name` 已滞后，可能组成另一个股票的名称和当前代码。截图证实错误组合，**无法仅凭截图证明造成该对象状态的具体浏览器事件顺序**。
- 现有 `quoteCoordinator.mjs` 会检查异步报价 `payload.code`，按代码处理请求先后顺序；`MarketChart`、恐贪、技术动能面板均已经按代码建立实例/验证响应身份。本轮不重做异步管线或重写算法。

## V2.0.0 最小修复

1. 新增只处理**证券身份/名称元数据**的纯函数 `resolveSelectedSymbol(selected, symbols)`，依据规范化当前代码匹配当前列表中的同一证券；没有匹配则保留当前选择，避免搜索列表临时切换时错误强制跳到另一只股票。
2. 主标题、名称/代码、报价读取、K 线、恐贪、技术动能、AI 分析入口统一读取 `selectedSymbol`，只允许代码匹配的目录行补全显示名称和市场。
3. 主标题 DOM 以“代码+名称”作为 key；切换股票/名称时重建该标题节点，防止旧标题 DOM 文本在重渲染后继续残留。图表和评分仍按代码建实例；不修改周期逻辑。
4. 新增前端可执行回归：`焦点科技 + HK.00772` 错配强制纠正为 `阅文集团 + HK.00772`；同时覆盖中美港多代码快速切换、反序目录、目录暂时不含已选股票、选中对象不可原地修改、图表/评分联动和节点 key。
5. 将网站页脚、发布镜像标签/OCI 版本、相应版本契约同步提升为 **V2.0.0**。不是引入新的 V2 产品模块。
