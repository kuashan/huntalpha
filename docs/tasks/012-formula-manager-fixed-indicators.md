# Task 012 — Django「公式管理器」与服务器固定公式

Status: `READY_FOR_CODEX`（2026-10-17 用户确认会员权限、源码保护和服务器已安装固定公式的后台自动展示；尚未实施）

## 背景

当前 Django Admin 应用 `formula_editor` 管理现有通达信 `Formula`，需要将后台展示名称调整为「公式管理器」，并分为「通达信公式」和「固定公式」。现有 4 条私人 Formula 属于数据而非 Git 文件，必须保留。已有固定 Python 公式 `CHANLUN` 注册在 `core/python_indicators.py`，通过 `core/chan_runner.py` 在服务器端计算，网页只接受绘图结果。不得重新实现 Chan.py 或把 Python 代码发送到浏览器。

## 必须实现

1. Django Admin 导航 / 页面以「公式管理器」呈现，清楚区分「通达信公式」与「固定公式」两类；原标题改名不能造成已有 Formula 表、主键或源代码迁移丢失。
2. 「通达信公式」现有 CRUD、服务器公式计算、版本、位置、启用状态、源码仅管理员可见及四个私有 Formula 内容全部保持不变；禁止通过新 API 泄露 `source`。
3. 固定公式**必须是仓库代码中明确注册的受控实现**，可复用 `core/python_indicators.py` 的定义/运行器。任何网页用户均不能上传、编辑或在浏览器执行 Python 代码；后台不提供固定公式 Python 源码编辑框。
4. **Django 后台自动展示服务器已正式部署、安装且受控注册的固定公式**：以当前运行版本的服务端注册表为唯一可执行公式目录，后台「固定公式（服务器已安装）」列表自动枚举已注册项目（初始至少包含 CHANLUN），展示公式代码、名称、版本、主图/副图位置和启用状态；新增通过独立审核的服务器固定公式并完成注册、部署后，不应为显示它再单独开发管理页面或手工维护展示名单。新增必要的轻量持久化状态，只有启用状态允许授权管理员修改，其余元数据来自服务端代码注册表且只读。不得扫描服务器目录并自动执行任意 `.py`、脚本或未注册代码；仅放置文件/仅创建数据库记录不构成已安装可执行公式。
5. `CHANLUN` 必须仍注册且默认启用（保持现有功能）；后续添加新的固定公式时只需经审核的服务端代码和受控注册，不允许任意文件路径、shell 命令、动态 import、`eval`。
6. 网站 `/api/indicators/` 应统一列出已启用的通达信/固定公式和原有常用指标；停用固定公式立即从正常列表移除，直接访问其 render API 也不得继续执行。启用后使用现有 `/api/indicator-render/<code>/<symbol>/` 服务器计算、网页绘图链路；**按以下用户确认的会员等级限制使用权限**，沿用原 visitor 边界。不可仅在前端隐藏按钮，后端 render API 必须同样验证真实账户等级并拒绝越权访问；级别变动后不得继续使用已失效的 PRO 权限/缓存结果。
7. 保持 Chan.py 算法、输出绘图结构、真实行情 Provider、SSE/Bar 联动和渲染语义不变；已有 private Formula 不因新功能改用第二套执行引擎。
8. **前台用户仅能添加或移除允许使用的指标**，所有 FREE/PRO 账户均不得从网站、前端资源、API/网络响应或日志读取/下载通达信私人公式源代码、固定公式代码；网页中只提供指标元数据和必要的绘图结果。保留原先单独受权限约束的 Django Admin 私人公式管理能力（第 2 项），它不属于普通网页用户的源码查看权限；后台固定公式仍不提供源码编辑框。不得另外增加公式下载、用户自定义编辑或策略自动交易。
9. **预装可选**：网站用户按权限选择预装指标，点击添加/移除后在现有 K 线图展示/移除；不自动启用交易、不因本任务擅自开发新的固定公式或新策略。

- 原有访客/未登录访问规则不自动扩大；访客保留原已允许的六个基础内置指标，CHANLUN 的免费授权仅针对已登录 FREE/PRO 账户。
- 后端使用 Task 011 真实持久化会员等级作为单一权限来源，不以浏览器 FREE/PRO 徽章、前端状态、工作人员身份推断可用等级。Task 011 不负责新增本指标权益，指标权限由本 Task 012 实现和测试。
- 无权限的私人/固定公式不得以直接请求 API、猜测代码、旧结果或账户降级后的浏览器状态绕过，响应不得包含源码。可在前端保留锁定的项目名称供识别，但不得让 FREE 成功运行或显示受限指标；不要求新增付费入口。
- “所有用户不能看到源码”适用于**网站前台的全部会员及访客**；管理员在独立 Django Admin 管理原有私人 Formula 的必要权限沿用此前获批边界，不扩大对普通用户的源码访问。
